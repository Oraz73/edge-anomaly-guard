# Как внести вклад

1. Создайте задачу (Issue) с описанием ошибки или улучшения.
2. Создайте ветку от `main`: `git checkout -b feature/краткое-название`.
3. Установите зависимости для разработки: `pip install -e ".[dev]"`.
4. Внесите изменения и добавьте тесты.
5. Проверьте локально:
   ```bash
   ruff check . && ruff format --check .
   pytest
   ```
6. Сделайте коммит с понятным сообщением в стиле Conventional Commits
   (`feat:`, `fix:`, `docs:`, `test:`, `ci:`) и откройте Pull Request.

Pull Request принимается только после успешного прохождения CI.
